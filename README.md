🌐 Webserv — Build Your Own HTTP Server
A C++98 project that consists in writing a fully functional HTTP server, from scratch, using low-level networking and non-blocking I/O with poll.

![ezgif com-video-to-gif-converter (4)](https://github.com/user-attachments/assets/7e5172ba-7831-4ada-8a41-b2dd4041b15d)

🧠 What You'll Learn
How the HTTP protocol actually works

How web servers handle requests, responses, and CGI

Mastery of sockets, non-blocking I/O, and I/O multiplexing

Writing a full server architecture with configurable virtual hosts, error pages, routing, and file uploads

⚙️ Features

   Handle GET, POST, DELETE
  
   Serve static files + directory listing
  
   Fully customizable via a config file (.conf style)
  
   One poll() (or equivalent) for all I/O
  
   Works in a real browser
  
   Built-in error pages
  
   Execute CGI scripts (like PHP or Python)
  
   Handle file uploads
